# Design Tokens

Design tokens (colors, typography, spacing, etc.) are a work in progress.

## Current Status

🚧 **Evolving Foundation**

The design system currently does not include a centralized token system. As the project grows, design tokens will be established to ensure consistency across components and applications.

## What's Coming

In the future, this section will document:

- **Color palette** — brand colors, semantic colors (success, error, warning, info)
- **Typography** — font families, sizes, weights, line heights
- **Spacing** — margins, padding, gaps (8px scale)
- **Elevation** — shadow definitions for depth
- **Interactions** — transitions, animations, durations
- **Sizing** — component sizing scale
- **Borders** — radius, width, styles

## For now

Component styling is managed by each component's implementation. Consumers can style components using CSS or CSS-in-JS solutions.

The unstyled nature of components means you have full control over appearance while maintaining semantic structure and accessibility.
