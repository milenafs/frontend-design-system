# Stack

A flexible layout component for creating consistent spacing between elements using flexbox.

## Overview

The Stack component simplifies common layout patterns by handling alignment, spacing, and direction in a declarative way. It's perfect for building forms, button groups, navigation, and other layouts.

## Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `direction` | `"horizontal" \| "vertical"` | `"vertical"` | Stack direction (flex-direction) |
| `gap` | `"xs" \| "sm" \| "md" \| "lg" \| "xl"` | `"md"` | Spacing between items (4px, 8px, 16px, 24px, 32px) |
| `align` | `"start" \| "center" \| "end" \| "stretch"` | `"stretch"` | Align items (align-items) |
| `justify` | `"start" \| "center" \| "end" \| "space-between" \| "space-around"` | `"start"` | Justify content (justify-content) |
| `children` | `ReactNode` | — | Stack contents |
| `...props` | `HTMLAttributes` | — | All div attributes |

## Usage

```tsx
import { Stack, Button, Input } from "@milfushi-design-system/ui";

export function LoginForm() {
  return (
    <Stack gap="lg" direction="vertical" style={{ maxWidth: "400px" }}>
      <Input label="Email" type="email" />
      <Input label="Password" type="password" />
      
      <Stack gap="md" direction="horizontal">
        <Button variant="secondary">Cancel</Button>
        <Button variant="primary">Login</Button>
      </Stack>
    </Stack>
  );
}
```

## Common Patterns

### Form Layout

```tsx
<Stack gap="lg" direction="vertical">
  <Input label="First Name" />
  <Input label="Last Name" />
  <Input label="Email" type="email" />
  
  <Stack gap="md" direction="horizontal">
    <Button variant="secondary">Cancel</Button>
    <Button variant="primary">Submit</Button>
  </Stack>
</Stack>
```

### Navigation

```tsx
<Stack gap="md" direction="horizontal" justify="space-between">
  <div>Logo</div>
  <Stack gap="md" direction="horizontal">
    <Button>Home</Button>
    <Button>About</Button>
    <Button>Contact</Button>
  </Stack>
</Stack>
```

### Card Grid

```tsx
<Stack gap="lg" direction="vertical">
  <Stack gap="md" direction="horizontal" style={{ flexWrap: "wrap" }}>
    <Card>Item 1</Card>
    <Card>Item 2</Card>
    <Card>Item 3</Card>
  </Stack>
</Stack>
```

- Proper focus management for interactive children
- No visual or semantic barriers to keyboard navigation
