# Checkbox

A native checkbox input with an optional associated label.

## Examples

```tsx
<Checkbox label="I agree to the terms" defaultChecked />
```

```tsx
<Checkbox
  label="Subscribe to newsletter"
  onChange={(e) => console.log(e.target.checked)}
/>
```

## Interactive Playground

For more examples and interactive testing, see the Checkbox component story in Storybook (run `npm run storybook --workspace=packages/ui`).
