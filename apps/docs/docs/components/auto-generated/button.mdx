# Button

A semantic button component with support for multiple visual variants.

## Examples

```tsx
<Button variant="primary" onClick={() => alert('Clicked!')}>
  Click Me
</Button>
```

```tsx
<Button variant="secondary" disabled>
  Disabled Button
</Button>
```

## Interactive Playground

For more examples and interactive testing, see the Button component story in Storybook (run `npm run storybook --workspace=packages/ui`).
