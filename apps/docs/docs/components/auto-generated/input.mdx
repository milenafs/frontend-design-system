# Input

A text input component with support for labels, helper text, and validation states.

## Examples

```tsx
<Input
  label="Email"
  type="email"
  placeholder="your@email.com"
  helperText="We'll never share your email"
/>
```

```tsx
<Input
  label="Username"
  variant="error"
  helperText="Username is already taken"
/>
```

## Interactive Playground

For more examples and interactive testing, see the Input component story in Storybook (run `npm run storybook --workspace=packages/ui`).
