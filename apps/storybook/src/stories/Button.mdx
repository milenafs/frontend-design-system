# Button

A semantic button component built on native HTML `<button>` elements.

## Overview

The Button component is a wrapper around the native HTML `<button>` element with support for variants and all standard button attributes. It maintains full semantic accessibility and keyboard support.

## Usage

```tsx
import { Button } from "@frontend-design-system/ui";

<Button variant="primary">Primary Button</Button>
<Button variant="secondary">Secondary Button</Button>
<Button disabled>Disabled Button</Button>
```

## Accessibility

The Button component maintains full semantic accessibility:

- Built on native `<button>` elements with automatic keyboard support
- Fully keyboard navigable (Tab, Enter, Space)
- Announces correctly to screen readers as a button
- Respects focus styles and tab order

## Styling

The Button component is **unstyled by default**. It renders a plain `<button>` element with a `data-variant` attribute:

```html
<button data-variant="primary">Button</button>
```

You can style the button using CSS by targeting `button[data-variant="..."]`.
